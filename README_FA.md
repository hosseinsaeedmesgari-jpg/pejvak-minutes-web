# PEJVAK Minutes — نسخه وب و آفلاین ۱.۳

**هدف:** ثبت صورتجلسه روی وب و کامپیوتر/گوشی، بدون آپلود اطلاعات جلسه. نسخه اندروید قبلی بدون تغییر باقی می‌ماند.

## انتشار در GitHub Pages با اکانت Free

**مخزن اندروید فعلی را Private نگه دارید.** یک مخزن عمومی جدید فقط برای کد رابط وب ایجاد کنید، مثلاً `pejvak-minutes-web`.

1. در GitHub Desktop گزینه `File → New repository` و نام `pejvak-minutes-web` را بزنید.
2. در `Repository → Show in Explorer` پوشه مخزن جدید را باز کنید.
3. فایل‌های داخل این بسته را **در ریشه مخزن** کپی کنید؛ فایل `PEJVAK_Local_PC.html` و فایل‌های راهنما اختیاری‌اند و نیازی به انتشار ندارند. فایل‌های پشتیبان شخصی `*.json` را هرگز داخل مخزن نگذارید.
4. `Commit to main` سپس `Publish repository` را بزنید و `Keep this code private` را **برای مخزن وب جدید غیرفعال** کنید (فقط برای GitHub Pages در پلن Free). کد رابط وب عمومی خواهد بود.
5. در وب‌سایت GitHub مخزن وب جدید: `Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save`.
6. آدرس وب پس از انتشار معمولاً شبیه `https://<username>.github.io/pejvak-minutes-web/` است؛ آن را از بخش Pages خود GitHub تأیید کنید.
7. با گوشی یا کامپیوتر لینک HTTPS را باز کنید، یک‌بار صفحه را کامل بارگذاری کنید و سپس از گزینه Install app / Add to Home screen مرورگر استفاده کنید.
8. بعد از آن برای کار آفلاین می‌توانید اینترنت را قطع کنید. **در اولین استفاده آفلاین بعد از انتشار، حتماً صفحه را یک‌بار آنلاین باز و بارگذاری کرده باشید.**

## کار کاملاً لوکال در کامپیوتر

فایل `PEJVAK_Local_PC.html` را جداگانه روی ویندوز نگه دارید و با Edge/Chrome باز کنید. اجرا به اینترنت نیاز ندارد. چون این نسخه از آدرس `file://` اجرا می‌شود، نصب استاندارد PWA فعال نیست و پایداری ذخیره‌سازی در فایل‌های محلی وابسته به مرورگر است. پیشنهاد اصلی برای استفاده درازمدت، نسخه نصب‌شده PWA از HTTPS و پشتیبان‌گیری منظم است.

## موارد مهم

- **اطلاعات جلسات، اعضا، امضاها و پیش‌نویس در localStorage مرورگر همان دستگاه باقی می‌مانند.** مخزن GitHub، GitHub Pages یا سرور میزبان اطلاعات جلسات شما را نمی‌گیرد.
- روی گوشی، کامپیوتر و APK سه محل ذخیره‌سازی جداگانه خواهید داشت. برای انتقال از منوی `پشتیبان‌گیری → دریافت پشتیبان JSON` و سپس `بازیابی پشتیبان` استفاده کنید.
- بازیابی، داده‌های فعلی همان دستگاه را جایگزین می‌کند؛ قبل از بازیابی خروجی JSON فعلی بگیرید.
- پاک‌کردن داده‌های سایت/مرورگر یا حذف برنامه نصب‌شده ممکن است رکوردها را پاک کند؛ بکاپ منظم مهم است.
- در GitHub Pages مخزن عمومی به معنای عمومی‌شدن **کد رابط و لوگو** است، نه اطلاعات ذخیره‌شده جلسات. از به اشتراک‌گذاری فایل‌های پشتیبان و اسناد محرمانه در GitHub خودداری کنید.
- این نسخه هیچ همگام‌سازی بین دستگاه‌ها ندارد، و یک سامانه چندکاربره روی سرور نیست.
- مرورگر برای PDF از `Print → Save as PDF` استفاده می‌کند. در حالت آفلاین هم این گزینه کار می‌کند.
- برای نسخه وب این بسته، فونت روی دستگاه استفاده می‌شود: در صورت نصب Vazirmatn آن را به‌کار می‌برد و در غیر این صورت `Segoe UI`/`Tahoma` جایگزین هستند.

## نسخه اندروید

نسخه اندروید در `PEJVAK_Android_GitHub` را تغییر نداده‌ایم. بسته وب مستقلاً منتشر می‌شود و سازوکار ساخت APK و اصلاحیه بازیابی JSON دست‌نخورده باقی می‌مانند. هر دو رابط از ساختار پشتیبان نسخه ۳ PEJVAK و همین کلیدهای داده پشتیبانی می‌کنند.
