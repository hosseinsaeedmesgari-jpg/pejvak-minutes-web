# PEJVAK Minutes v1.4 — امضای غیرحضوری و بارگذاری در اندروید و وب

## قابلیت‌های جدید
- بارگذاری عکس PNG/JPG/WebP یا فایل JSON ساخته‌شده توسط PEJVAK Sign در بخش امضاهای همان جلسه
- برش حاشیه‌ها با اسلایدر، حذف **اختیاری** پس‌زمینه سفید و پیش‌نمایش قبل از ثبت
- ثبت روش دریافت، تاریخ شمسی، توضیحات و تأیید اجازه استفاده از امضا
- هشدار تطابق نام امضاکننده و شماره جلسه برای فایل PEJVAK Sign
- در خروجی PDF، مشخص‌شدن «بارگذاری‌شده توسط تنظیم‌کننده» برای امضاهای دریافتی
- صفحه مستقل `sign.html`: امضا با انگشت/قلم، خروجی JSON تأییدیه قابل بارگذاری و PNG، دانلود یا اشتراک‌گذاری از گوشی
- ساخت و اشتراک لینک صفحه امضا در داخل وب و اندروید؛ در اندروید آدرس واقعی `sign.html` را یک‌بار وارد کنید

## معماری و حریم خصوصی
هیچ حساب کاربری، سرور، ارسال خودکار امضا یا همگام‌سازی اضافه نشده است. صفحه امضا اطلاعات را به GitHub ارسال نمی‌کند؛ فرد خودش فایل را دانلود یا ارسال می‌کند. PDF جلسه را جداگانه و با مجوز برای امضاکننده بفرستید؛ در لینک عمومی جزئیات محرمانه ارسال نکنید.

فایل امضا به‌تنهایی هویت امضاکننده یا اعتبار گواهی دیجیتال را اثبات نمی‌کند. تنظیم‌کننده باید تأیید و اجازه استفاده را بررسی کند.

## آپدیت Android (مخزن خصوصی قبلی)
1. قبل از آپدیت از داخل اپ `پشتیبان‌گیری → دریافت پشتیبان JSON` بگیرید.
2. **فقط محتویات ZIP به‌روزرسانی اندروید** را داخل پوشه مخزن اندروید GitHub Desktop کپی و Replace کنید.
3. Commit سپس Push origin معمولی انجام دهید. `.github/workflows/build-apk.yml` در ZIP آپدیت وجود ندارد تا Merge Conflict ایجاد نکند.
4. APK را از GitHub Actions دریافت کنید. برای حفظ داده‌ها از نسخه قبلی بدون حذف برنامه، باید بسته/کلید امضا یکسان باشد.

## آپدیت Web (مخزن عمومی pejvak-minutes-web)
1. **فقط محتویات ZIP به‌روزرسانی وب** را در پوشه مخزن وب کپی و Replace کنید.
2. Commit/Push origin و منتظر موفقیت Pages deployment بمانید.
3. صفحه عمومی امضا در `<آدرس سایت>/sign.html` قرار می‌گیرد. می‌توانید لینک آن را برای افراد ارسال کنید.
4. در صورتی که صفحه قبلی در کش مانده باشد، مرورگر را Refresh کنید یا PWA را دوباره باز کنید.

## تست کاربردی پیشنهادی
1. یک صورتجلسه آزمایشی با شماره `MM-001` بسازید.
2. لینک `/sign.html` را باز کنید؛ نام، `MM-001` و امضا را وارد، تیک موافقت را فعال و خروجی JSON بگیرید.
3. در صورتجلسه همان شخص، `بارگذاری امضا` را بزنید، فایل JSON را وارد کنید، روش دریافت و تاریخ را انتخاب و اجازه استفاده را تأیید کنید.
4. پیش‌نمایش PDF و سپس خروجی را بررسی کنید.
5. از اپ بکاپ بگیرید؛ پاک‌کردن داده یا پاک‌کردن برنامه بدون بکاپ ممکن است داده‌ها را حذف کند.

## توجه به فایل PEJVAK_Local_PC.html
این فایل یک نسخه تک‌فایلی برای اجرای کامپیوتر است. آدرس `sign.html` واقعی فقط بعد از انتشار وب روی GitHub Pages فعال می‌شود. فایل `PEJVAK_Sign_Local_PC.html` هم برای تست صفحه امضا بدون سرور است.
